# Update v1 fixed vector

Public TEST-ONLY RFC 8032 section 7.1 seed. These bytes are not release credentials.
Generate with `node generate.cjs` from this directory or its full path. Node/OpenSSL signs and verifies the independently assembled preimage. The Kotlin test verifies the committed envelope using JCA and reproduces the exact signature with the published seed. No dependency download is needed.

payload.bin is UTF-8 and ends in LF; it is an opaque verifier fixture, deliberately not a complete Module 3 payload schema. envelope.json ends in LF. preimage.hex also ends in LF; preimage.bin and signature.bin have no added terminator. sha256.json inventories the generated byte files. Production registries reject test- key IDs. There is no production signing key here.
