# Riff 0.9.0-rc3

> **Historical record.** This document describes earlier work and is kept as it was written. It is not current documentation and may not match the code. Current documents: [documentation index](README.md). Current plan: [Riff excellence implementation plan](RIFF_EXCELLENCE_IMPLEMENTATION_PLAN.md).

- Smoother, interruptible player and navigation motion with shared reduced-motion behavior.
- Large-text navigation and mini-player adjustments.
- Clear glass centers with lower rendering cost; edge refraction remains.
- Original demo music, album art, podcasts, Radio, playlists, lyrics and local offline copies remain available.
- Real YouTube Music search and saved rows are browse-only. Playback, remote downloads, cloud sync, collaboration, Cast, AI and billing are unavailable in this release.

Signed APK and source ZIP hashes are in `artifacts/release/SHA256SUMS.txt`. Device limitations and test results are in `phase-10-rc3-handoff.md`.
