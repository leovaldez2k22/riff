# UI polish — 2026-09-30

> **Historical record.** This document describes earlier work and is kept as it was written. It is not current documentation and may not match the code. Current documents: [documentation index](README.md). Current plan: [Riff excellence implementation plan](RIFF_EXCELLENCE_IMPLEMENTATION_PLAN.md).

Version 0.9.0-rc5 (versionCode 6) implements the requested player and Home refinements. Uses the existing release key and same application ID.

## Changes

1. Artwork fades through transparency across the bottom of the image into a single background spanning the player. The same artwork mask is used during the mini/full-player transition. Separate image and controls background gradients are removed.
2. Volume track is 4 dp with a 12 dp circular thumb. The ordinary slider touch target and system-volume controls remain.
3. Player and mini-player artist labels omit provider name, album, duration and view-count suffixes. Provider type prefixes such as Song and Video are skipped to retain the actual artist. Seek elapsed/remaining times remain on the seek control.
4. Home starts at the status-bar inset plus 2 dp with no leading spacer; other screen lists use inset plus 4 dp. Player top controls use inset plus 2 dp. Home vertical spacing is smaller.
5. Account-menu parsing reads structured account-name text and the active header's actual accountPhoto. Selected-account fallback handles account-list responses. Google profile image hosts under ggpht.com are supported and resized appropriately.
6. The signed-in name is shown in the greeting. Profile fetching is independent from Home recommendations; signing out clears the profile. No fabricated Hello User identity is displayed.
7. Home categories participate in live backdrop refraction and have translucent highlights and 0.65 dp borders. Category padding is smaller; navigation outer borders and selector borders are thinner. Solid-controls accessibility mode remains available.
