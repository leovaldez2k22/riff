# Desktop architecture decision 001

Status: accepted for the Windows 11 feasibility milestone by the owner's implementation instruction, 1 November 2026. Release readiness remains conditional on M1 acceptance evidence.

Use an opt-in :desktop JVM/Compose module. Android :app and :benchmark retain their boundaries. Kotlin/compiler 2.4.10, Compose Multiplatform 1.12.2 and JDK 21 are pinned. This is an additive desktop exception to the Android-only module rule, not permission for broad Android reorganization.

A persistent desktop host owns state and native resources; views own only rendering/input. Close exits while tray is unavailable. M2 may add Mini-Player without creating a second playback engine; M3 adds the native worker; M5 adds the tray. Explicit Quit always releases the host. Native handles and subclass callbacks are disposed with their window.

Glass preserves Riff's Android shader and optical equations; the Skia adapter replaces Android RenderEffect and pre-draw integration. Backdrop recording excludes glass consumers, avoiding recursive capture. No WebView or CSS blur substitute is accepted as parity. Full, Reduced, Frost and Solid remain distinct modes.

Default builds remain Android-only. Desktop uses -PriffDesktop=true and must pass its own tests, package and acceptance gates in addition to the existing PR lane. Electron remains a decision fallback if Compose rendering/accessibility gates cannot be met; no silent renderer replacement is authorized.
