# M1 reference captures

These are manual inspection captures of the packaged gallery, not approved pixel-golden images or proof of Android parity. `m1-full-20261101.jpg` and `m1-timing-20261101.jpg` use the `riff.referenceGallery=true` fixture: palette 0, paused clock at 2.50 seconds, 1280 × 800 captured window, with Full glass. The second capture has the timing panel open. JPEG compression and the visible cursor prevent pixel-exact comparisons.

The generated rainbow artwork is synthetic. The Android `docs/images/player.png` shows a different screen, artwork and state, so comparing these files cannot establish per-component optical, typography or animation parity. Fixed-state Android component captures and owner perceptual review remain open. Source hashes are in `../reference-manifest.json`.
