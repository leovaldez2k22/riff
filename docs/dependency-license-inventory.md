# Direct dependency and asset inventory for 0.9.0-rc3

The resolved release runtime graph is `artifacts/release/dependencies.txt`. The complete coordinate-by-coordinate audit is `dependency-license-audit.csv`, generated by `scripts/audit_dependency_licenses.py` from that graph and the local Gradle POM cache. It covers 206 resolved dependencies: 202 POM declarations and four upstream-verified declarations where the POM omitted a license (three Guava modules and SLF4J). The audit found 203 Apache-2.0 modules, two GPL-3.0 modules and one MIT module. This is an inventory of metadata, not a review of every included notice or source file for public distribution.
